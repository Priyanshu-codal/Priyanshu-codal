## 🎯 About Me

I am a **Software Engineer at [Codal](https://codal.com)** specializing in **Shopware 6** and **Symfony** enterprise development. My day-to-day work centers around designing robust backend architectures, decoupled messaging pipelines, and mission-critical ERP/eCommerce integrations that power large-scale enterprise storefronts.

- 🛍️ **Shopware 6 Enterprise Architecture**: Core decoration, Data Abstraction Layer (DAL) extensions, Rule Builder engines, and custom plugin development targeting Shopware 6.7.x with 6.8 readiness.
- ⚡ **Asynchronous Messaging & Queues**: Engineering distributed event consumers and background workers powered by **RabbitMQ** and Symfony Messenger.
- 🔍 **High-Performance Search**: Catalog indexing and optimized query building using **Elasticsearch** and **OpenSearch**.
- 🔄 **Enterprise Integrations**: Building resilient data import orchestration layers, trade agreement pricing pipelines, and automated webhook event handlers.
- 📐 **Clean Code & Quality**: Strict adherence to **PSR-12**, static analysis with **PHPStan** (level 8/max), strict typing (`declare(strict_types=1)`), and comprehensive PHPUnit test suites.

### 🔄 Asynchronous Messaging & Orchestration Architecture

```text
┌──────────────────────┐      Webhook / API       ┌───────────────────────────┐
│ External ERP / D365  │ ───────────────────────> │ Shopware Orchestration    │
└──────────────────────┘                          └─────────────┬─────────────┘
                                                                │ Async Message Bus
                                                                ▼
┌──────────────────────┐   Buffered Background    ┌───────────────────────────┐
│ Elasticsearch / DAL  │ <─────────────────────── │ RabbitMQ Queue Consumers  │
└──────────────────────┘       Worker Pool        └───────────────────────────┘
```

- **Decoupled Workflows**: Offloading intensive trade agreement calculations and customer sync to asynchronous RabbitMQ consumers.
- **Failover & Retry Architecture**: Dead-letter exchange handling with automated replay mechanisms to ensure zero transaction loss.
